# eou_sde_dataset_sde_to_gh

Script runner para generar mappings desde el SDE oficial (CCP) y escribirlos en `data/gh_sde/`.

- Runner: `ops/gh_sde/eou_sde_dataset_sde_to_gh.sh`
- Salidas: `gh_sde_ss.jsonl.gz`, `gh_sde_rg.jsonl.gz`, `gh_sde_ty.jsonl.gz`, `gh_sde_st.jsonl.gz`, `gh_sde_sg.jsonl.gz`
- Meta: `data/gh_sde/eou_sde_dataset_sde_to_gh.json`
